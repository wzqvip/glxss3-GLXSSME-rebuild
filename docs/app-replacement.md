## 定位

一个干净的、开源的非商业重新实现：

- 直接走 USB（Android USB Host API），不依赖任何私有 SDK 或 native 库；
- 复用本仓库逆向出的协议（16 B 头 + RGBA 帧、UVC、HID、固件引导）；
- 提供比原厂更好的投屏体验（适应/裁剪/拉伸、实时缩放/偏移、错误提示、自动恢复）。

## 里程碑（现状）

| 阶段 | 内容 | 状态 |
|---|---|---|
| M0 | USB 连接 + 发测试图（纯色/色条） | ✅ |
| M1 | MediaProjection 实时投屏 + 画面模式 | ✅ |
| M2 | 控制命令（亮度/开关/roll/模式）+ 断开/恢复 | ✅ |
| M3 | UVC 摄像头预览/拍照 + 音频 + 固件自动加载 | ✅ |
| M4 | HID 语义、录像、1080p、NPU（研究项） | ❌ / 待验证 |

技术选型：Kotlin + Jetpack Compose，`minSdk 26 / targetSdk 35`，AGP 8.7.3，无第三方运行时依赖。
